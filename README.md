# Notify — A MERN Notes App

A full-stack note-taking application with authentication, rich text editing, soft-delete/trash, profile management, and bulk import/export — built as part of Cohort 9.

## Features

- **Authentication** — signup, login, logout with HttpOnly cookie-based sessions (JWT stored server-side in a cookie, never exposed to client-side JavaScript)
- **Notes** — create, edit, and delete notes, with content stored as rich HTML
- **Rich text editing** — powered by Tiptap: bold, italic, underline, strikethrough, headings, bullet lists, undo/redo
- **Trash** — deleting a note soft-deletes it; restore it from Trash, or delete it permanently
- **Search** — filter notes by title or content
- **Import/Export** — back up all your notes to a `.txt` file, or bulk-import notes from one, with a preview step before either action completes
- **Profile** — view your account details and upload/change a profile picture (images are re-encoded server-side via `sharp` before being saved)
- **Responsive layout** — usable on both desktop and mobile, with a collapsible sidebar and a mobile-friendly note detail view

## Tech Stack

**Frontend**
- React + TypeScript (Vite)
- Tailwind CSS
- React Router
- Tiptap (rich text editor)
- DOMPurify (sanitizing rendered HTML)

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT auth via HttpOnly cookies
- bcrypt (password hashing)
- Multer + Sharp (profile picture upload & processing)
- Pino + pino-http (structured logging, including all HTTP requests/responses)
- node-cron (scheduled trash auto-purge)
- Centralized error-handling middleware

**Testing**
- Backend: Mocha, Chai, chai-http, mongodb-memory-server (isolated in-memory MongoDB per test run), nyc (coverage)
- Frontend: Jest, React Testing Library

**Code Quality**
- SonarQube Cloud, integrated via GitHub Actions — analyzes both frontend and backend on every push/PR, using coverage reports generated by the test suites above

## Getting Started

### Prerequisites
- Node.js 20+
- A MongoDB connection string (local or Atlas)

### 1. Clone and install

```bash
git clone <repo-url>
cd cohort-9-mern-7127-uzair

cd backend && npm install
cd ../frontend && npm install
```

### 2. Configure environment variables

**`backend/.env`**
```
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
JWT_EXPIRES_IN=7d
FRONTEND_URL=http://localhost:5173
LOG_LEVEL=info
```

**`frontend/.env`**
```
VITE_API_URL=http://localhost:5000
```

### 3. Run in development

```bash
# backend
cd backend
npm run dev

# frontend, in a separate terminal
cd frontend
npm run dev
```

The frontend runs on `http://localhost:5173`, the backend on `http://localhost:5000`.

## Testing

Both test suites run against isolated environments — the backend spins up a temporary in-memory MongoDB instance per run (nothing touches a real database), and the frontend mocks all service calls so no real network requests are made.

```bash
# backend
cd backend && npm test

# frontend
cd frontend && npm test
```

Coverage for both is collected in CI and fed into the SonarQube analysis on every push and pull request — see `.github/workflows/` for the pipeline definition and `sonar-project.properties` for the SonarQube configuration.

## API Overview

**Auth** (`/auth`)
| Method | Route | Description |
|---|---|---|
| POST | `/signup` | Create an account |
| POST | `/login` | Log in, sets an HttpOnly session cookie |
| POST | `/logout` | Clear the session cookie |
| GET | `/me` | Get the logged-in user's profile |
| POST | `/profile-picture` | Upload/replace the profile picture |

**Notes** (`/notes`)
| Method | Route | Description |
|---|---|---|
| GET | `/` | List the logged-in user's active notes |
| POST | `/` | Create a note |
| PUT | `/:id` | Update a note |
| DELETE | `/:id` | Soft-delete (move to trash) |
| GET | `/trash` | List soft-deleted notes |
| PATCH | `/:id/restore` | Restore a note from trash |
| DELETE | `/:id/permanent` | Permanently delete a trashed note |

All `/notes` routes and `GET /auth/me` / `POST /auth/profile-picture` require a valid session cookie.
